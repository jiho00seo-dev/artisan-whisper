# ✍️ Whisper Agent: 프리미엄 큐레이션 작성 워크플로우

대표님, 이제 상품 설명도 박이사가 제안하는 '신뢰의 목소리'로 입혀보겠습니다.

## 1. 페르소나 설정 (Persona Mapping)
제품이 아래 중 어디에 최적화되어 있는지 선택합니다.
- `#men30`: 실용과 품격의 균형 (예: 가죽 데스크 매트)
- `#natural`: 따스함과 편안함 (예: 수제 도자기 컵)
- `#gift`: 주는 이와 받는 이의 안목 (예: 우드 디퓨저)

## 2. 고감도 문구 작성 (Tone & Manner)
- **첫 문장**: 기능을 말하지 말고 '장면'을 말하세요.
  - *BAD*: "튼튼한 가죽으로 만든 마우스 패드입니다."
  - *GOOD*: "차분한 서재의 공기, 손끝에 닿는 이 가죽의 질감은 오늘의 업무를 여유롭게 바꿉니다."
- **핵심 특징**: 장인의 정성을 강조 (예: '30시간의 태닝 과정', '손으로 빚어낸 비정형의 미학')
- **마무리**: 이 제품이 왜 '당신'을 위한 것인지 정의.

## 3. `curation-data.js` 업데이트 포맷
작성된 카피를 아래 형식에 맞춰 정리합니다.

```javascript
{
    id: "product_id_here",
    persona: "target_persona",
    title: "감성적인 상품명",
    tag: "#핵심_태그",
    desc: "여기에 Whisper Agent가 작성한 문구 삽입",
    img: "이미지_URL",
    url: "junction.html?id=product_id_here"
}
```
